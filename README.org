** Search Algorithm Comparison

The searching binary can find a specific target value in the randomly generated list.
The four algorithms that are compared are
- Linear Search
- Binary Search
- Quaternary Search
- Rust inbuilt Search

#+begin_src shell :export both :results output
cargo run --release --bin search_algo_comparision -- -t 102
# cargo run --release --bin sort_algo_comparision
#+end_src
